# Shapez 2 Co-op — экспериментальная сборка

**Это alpha, а не готовый мод для полноценного прохождения.** Сборка проверена против Steam Windows 1.2.0-rc3. Протокольные тесты не доказывают корректность симуляции. Подтверждённые проверки и их ограничения приведены в `TESTING.md`.

Реализованы: унаследованный интерфейс Steam/IP и курсоры, ограничение хост + три клиента, проверка совместимости сборок, подтверждение строительства/удаления/чертежей/исследований хостом, отклонение устаревших команд, снимок мира в памяти при подключении, надёжная передача с SHA256 и лимитами, фиксированные шаги симуляции и остановка при несовпадении контрольных сумм. Клиентские сохранения заблокированы; общий мир сохраняет хост.

В alpha.3 исправлены обслуживание ENet при загрузке и порядок проверки грузовых платформ. Расчёт использует штатные рабочие потоки игры, периодические проверки распределены по кадрам. Отставание клиента ограничено, упаковка снимка выполняется отдельно. Подробности — в [ARCHITECTURE.md](ARCHITECTURE.md) и TESTING.md.

## Установка для испытаний

1. У всех участников должны совпадать игра, эта сборка и набор модов. Отключите исходный [Shapez2Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=3723300107). Установите зависимости из Workshop: [HarmonyX](https://steamcommunity.com/sharedfiles/filedetails/?id=3720742050), [Steamworks Platform Resolver](https://steamcommunity.com/sharedfiles/filedetails/?id=3720740565), [Shapez2UILib](https://steamcommunity.com/sharedfiles/filedetails/?id=3735218203). Их DLL не входят в этот архив.
2. Закройте игру. Распакуйте архив. Выполните `Install.ps1 -ModsDirectory '<ваш каталог данных Shapez 2>/mods'`. Каталог данных можно открыть через интерфейс игры. Установщик отказывается перезаписывать существующую папку и не обращается к сохранениям или Steam-установке. Для удаления уберите созданную папку `Shapez2Coop` при закрытой игре.
3. Включите локальный мод. Для испытаний создайте отдельную фабрику. Хост открывает паузу → Multiplayer → Host. Клиент подключается через Multiplayer из главного меню: Steam-приглашение или IPv4 хоста. IP использует UDP 7777; для интернета потребуется доступность порта на стороне хоста. Steam-релей требует работающий Steam.

После разрыва клиент возвращается в меню и подключается заново: он получает свежий снимок. Миграции хоста нет. При ошибке контрольной суммы сессия останавливается; автоматическое восстановление поверх работающей фабрики пока не реализовано.

В панели Multiplayer хост выбирает частоту симуляции **20 / 30 / 60 Гц**, в том числе во время сессии. Частота передаётся в снимке подключения и меняется у всех на общей границе шага. Клиенты не могут менять её самостоятельно. Выбор хоста сохраняется в отдельном `coop-settings.json` в каталоге данных игры. При перегрузке хоста общий мир замедляется; клиенты продолжают выполнять все шаги без пропусков. Проверки состояния выполняются каждые пять секунд игрового времени при любой частоте.

«Instant previews» включает локальное визуальное предсказание: строительство сразу показывает полупрозрачный предпросмотр, удаление — красную отметку ожидаемого удаления. Объект остаётся в авторитетном мире до ответа хоста. Подтверждение заменяет предпросмотр результатом, отказ убирает отметку без изменения мира. Предпросмотры ограничены 64 запросами и 2048 объектами; сверх лимита команда отправляется без предпросмотра. Переключатель сохраняется локально. Строительство и удаление зданий проверены в игре; предпросмотр платформ и больших чертежей ещё требует визуальной проверки.

## Ограничения alpha

- Локальные игровые проверки покрывают небольшую фабрику на 20/30/60 Гц и предоставленную большую фабрику (289 840 зданий): подключение, строительство, удаление, отклонение устаревшей команды и повторный вход. Steam-релей, интернет и длительное прохождение не подтверждены.
- Общий детерминизм и каноничность всех сериализаторов ещё не установлены. Совпадение проверялось также с разным числом штатных рабочих потоков. При перегрузке любого участника общая симуляция замедляется, проверки и шаги не пропускаются. 60 Гц не гарантирует такую скорость на большой фабрике.
- При подключении остаётся разовая остановка симуляции для согласованного снимка, полная проверка мира и нативная загрузка клиента. Большой мир может задержаться на несколько секунд. Длительная стабильность памяти пока не измерена.
- Undo/redo в кооперативе отключены. Команда до 120 КиБ; большие чертежи требуют разбиения. Снимок до 64 МиБ в сжатом виде, распакованный пакет до 128 МиБ.
- Одновременные правки разрешаются консервативно: после подтверждения одной правки запрос со старой ревизией отклоняется, даже если участки не пересекаются. Повторите действие; сообщение видно в панели Multiplayer.
- Проверка совместимости учитывает версию игры и MVID основных сборок, но проверка полного набора сторонних модов ещё не закончена.
- Прямое IP-подключение пока не имеет пароля. Используйте только закрытую тестовую сеть с доверенными участниками.
- Интерфейс и часть кодеков унаследованы; поддержка всех настроек зданий, операций исследований и чертежей требует игровых регрессий.

## Сборка

Исходники распространяются по GPL-3.0, см. LICENSE и THIRD-PARTY.md. Игровые DLL не распространяются.

Из корня проекта:

```powershell
./mod/tools/bootstrap-sdk.ps1
git clone https://github.com/Bknibb/Shapez2UILib local/Shapez2UILib
./mod/tools/build.ps1 -GameDirectory '<Steam>/steamapps/common/shapez 2'
./local/tools/dotnet/dotnet.exe run --project mod/tests/ProtocolTests -c Release
./mod/tools/package.ps1
```

SDK и кэш зависимостей размещаются в `local/`, результаты — в `mod/src/bin/Release` и `dist/`. `build.ps1` не устанавливает мод в игру. Для воспроизводимой сборки UI-зависимость должна соответствовать версии/commit в `DEPENDENCIES.json`. QA-бот компилируется только с `CoopQa=true`; обычная сборка его не содержит.

Перед упаковкой сохраните изменения в Git. `package.ps1` использует явный список DLL, проверяет отсутствие QA-бота и хеши ENet. Архив содержит установщик, лицензии, соответствующие исходники и `BUILD.json` с хешами файлов и коммитом. Игровые DLL и Workshop-зависимости не включаются. Протокол версии 2 несовместим с предыдущей alpha: обновляйте мод у всех участников одновременно.
